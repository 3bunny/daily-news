This paper introduces Agentao, a new runtime environment designed to enhance the security and governability of tool-using Large Language Model (LLM) agents. As LLM agents increasingly interact with external tools, modify local data, and use persistent memory, they introduce risks such as over-privileged actions, prompt injection vulnerabilities, and uncontrolled side effects. Agentao addresses these concerns through a layered architecture that explicitly separates an agent's proposed actions from their authorized execution. It incorporates a permission-mediated tool system, robust state management, and detailed execution traces to improve auditability and control. This development is crucial because as LLM agents become more integrated into real-world applications, ensuring their safe and secure operation is paramount. Agentao aims to make these powerful autonomous systems more trustworthy and suitable for sensitive tasks by providing explicit mechanisms for oversight and risk mitigation, moving towards more responsible AI deployment.

Reward Machines for Signal Temporal Logic

cs.AI updates on arXiv.orgAug 17, 13:00 KST

arXiv:2608.13625v1 Announce Type: new Abstract: Signal temporal logic (STL) provides a formal language for specifying real-time properties of real-valued observations, along with a quantitative robustness score for monitoring satisfaction. Control synthesis from STL specifications is of interest since manual …

Read more
This paper introduces a novel method for training reinforcement learning (RL) agents to adhere to complex, real-time specifications expressed in Signal Temporal Logic (STL). STL provides a formal language for defining desired system behaviors over time, crucial for safety-critical applications. A key challenge in using STL with RL is that the 'robustness score' (quantifying satisfaction) depends on the entire execution history, leading to an intractable state space for long-horizon tasks. The proposed solution constructs a 'timed alternating automaton' from the STL specifications, which efficiently augments the RL agent's state space with automaton locations. This provides an effective memory mechanism and generates Markovian rewards suitable for standard RL frameworks. This work is significant because it makes it more feasible to apply RL to control systems requiring formal guarantees, enabling autonomous systems (like robots or self-driving cars) to learn complex behaviors while reliably satisfying predefined safety and performance specifications, even without precise system models.
