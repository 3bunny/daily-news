Read more
Long-context Large Language Models (LLMs) are powerful, but their inference speed is often bottlenecked by the 'prefill' stage, where the entire input prompt is processed by dense self-attention before text generation begins. This process is computationally intensive. Researchers have introduced RBS-Attention, a training-free method designed to significantly accelerate this prefill phase by employing sparse attention. Traditional sparse methods can suffer from 'mean dilution,' where a highly relevant token might be overlooked if it's averaged with many irrelevant ones within a selected block. RBS-Attention addresses this with two complementary selection branches: a centroid base branch captures average relevance, while a 'rescue branch' specifically identifies blocks at risk of underestimation by considering the maximum key-block radius. By independently thresholding and combining these branches, it controls the contribution of rescue blocks while maintaining efficient FlashAttention execution. This matters because RBS-Attention achieves substantial speedups (e.g., 20.65x standalone prefill speedup), making long-context LLMs more efficient and practical for real-world applications. By reducing the time-to-first-token, it enhances user experience and lowers the operational costs associated with deploying these advanced models, pushing the boundaries of what's feasible with long-context AI.

Benchmarks like the Abstraction and Reasoning Corpus (ARC) are designed to test an AI model's ability to solve novel reasoning tasks, but it's often unclear whether success reflects genuine rule inference or merely reliance on superficial patterns. This research addresses that ambiguity by studying test-time task embeddings in Vision ARC (VARC) models, which use a pre-trained backbone complemented by a trainable embedding representing the transformation rule. The researchers introduced a novel two-step Test-Time Training (TTT) protocol called Embed-TTT. Unlike original VARC, Embed-TTT first finetunes only the small task embedding, then freezes it and finetunes the backbone. This method consistently yielded improved task embeddings that align more accurately with the underlying task rules, enhancing embedding-based retrieval and enabling precise linear probing of known rules across various datasets. This work is significant because it helps to distinguish between true abstract reasoning and shortcut learning in AI. By making the learned task representations more semantically meaningful and aligned with the actual rules, Embed-TTT pushes AI models closer to achieving human-like fluid intelligence and genuine generalization, providing a clearer understanding of how AI models interpret and apply abstract concepts in novel situations.

Self-play methods, where a language model co-trains as both a code generator and a test author, hold promise for advancing code generation beyond fixed test suites. However, these methods often suffer from two critical issues: 'permissiveness collapse,' where models generate trivial tests that always pass, and 'concentration bias,' where sampled tests are redundant and inflate performance estimates. Researchers introduced CoVer (Co-trained Coder and Verifier), a single-policy GRPO framework to mitigate these problems. CoVer employs an information-gain (IG) reward system that scores each self-generated test based on its mutual information with a graded, ground-truth-anchored correctness signal. This ensures that only positively discriminative tests receive reward. Additionally, a three-stage diversity-aware selection process prunes candidate tests into a non-redundant suite, filtering for invalidity, input-string uniqueness, and execution-profile diversity, thereby maximizing the effective sample size of the IG estimator. This innovation is crucial for developing more reliable code-generating AI. By ensuring that generated tests are both discriminative and diverse, CoVer helps models learn to produce robust and generalizable code. This leads to improved performance on various code generation benchmarks, making AI-assisted code development more trustworthy and efficient for complex programming tasks.
